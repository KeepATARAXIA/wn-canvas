# Bootstrap / 首次引导安装

本工具随首次引导 ZIP 分发，从解压包目录运行，不安装进画布目录。使用目标项目现有 Node；不安装依赖、不执行 Git、不停止进程、不启动后台。仅支持已核验的 `WN-20260924-01` 程序来源；没有分发标识时仍逐项校验来源哈希。

## Trust / 首次信任

先通过发布者的可信交付渠道取得 ZIP，并核对发布者单独提供的整包 SHA256，再执行包内工具。`verify` 校验清单与载荷一致性，不能证明包的发行者身份。首次公钥及更新地址由可信引导包建立，此后在线清单使用 Ed25519 验证；私钥不在本包中。

## Commands / 命令

将以下两类路径替换为真实的绝对路径；含空格或中文时使用引号。

```text
<项目内 Node 绝对路径> <解压包>/cli.mjs verify
<项目内 Node 绝对路径> <解压包>/cli.mjs check --project <WN-Canvas 项目绝对路径>
<项目内 Node 绝对路径> <解压包>/cli.mjs apply --project <WN-Canvas 项目绝对路径>
<项目内 Node 绝对路径> <解压包>/first-download.mjs --project <WN-Canvas 项目绝对路径>
<项目内 Node 绝对路径> <解压包>/cli.mjs rollback --project <WN-Canvas 项目绝对路径>
```

1. `verify`、`check` 均为只读。先检查来源、范围、载荷和更新源公钥；发生冲突须先报告，不覆盖自定义内容。
2. 保存工作，停止全部画布及模型后台，再执行 `apply`。仅关闭网页不能停止后台。工具检查默认端口 3000、8188、8189、17371–17374；使用自定义端口或其他启动方式时仍需人工确认后台全部退出。
3. `apply` 安装清单指定恢复入口、首次信任配置和明确列出的 H3 程序修复，保留模型、依赖、作品、个人配置及旧分发标识，不登记新在线版本。配置已存在且字节不同会停止，不能更换现有公钥。
4. `first-download` 只调用已校验更新器的检查、签名验证和下载准备流程。它不会安装程序。正式清单尚未发布、文件冲突或下载失败均会报错并保留当前程序。
5. 下载成功后，确认所有后台停止，再一键启动。新版网页载入后完成在线版本确认；下载完成不能代表安装验收通过。

## Recovery / 恢复与回滚

备份与事务在目标 `.wn-bootstrap/` 中，在线更新状态仍在 `.wn-updates/` 中；保留两者及本解压包。安装中断后，使用同一包重新执行 `apply` 会先恢复旧内容并报告 `rolledBack: true`，核对后再次 `apply` 才安装。正常重复应用只在全部文件仍为目标内容时返回已完成，不重写原恢复范围。

需要回滚引导入口时，保存工作并停止后台，再执行 `rollback`。如已下载待安装的在线版本、存在未结束的在线事务或已确认在线版本，先用在线更新器取消、恢复或回滚在线更新，然后回滚引导包。否则移除更新器会破坏在线恢复入口，工具会拒绝执行。

回滚前全量检查目标与备份；更新后又有本地修改时停止，保留现场。工具只恢复自己实际修改的路径，首次已存在的相同配置会保留，不批量删除目录。

## Package Contract / 清单约定

`manifest.json` 使用 `format: 1`、`kind: "wn-canvas-bootstrap"`、`sourceVersion: "WN-20260924-01"`、`feedUrl`、`publicKey`、`sourceChecks` 和 `files`。每项文件包含 `path`、`before`（旧 SHA256 或新增为 null）、`after: { sha256, size }`。载荷在 `payload/<相对路径>`，不支持删除操作。配置文件必须由 `configBytes(manifest)` 生成，并与清单公钥和 HTTPS 地址一致。

`sourceChecks` 必须包含 `web/package.json`、`web/package-lock.json`、`canvas-agent/package.json`、`canvas-agent/package-lock.json` 四项 `{ path, sha256 }`，使用正式来源的真实 SHA256。它们只用于兼容检查，不放入载荷、不安装或覆盖依赖；缺失、旧版或自定义依赖均停止并报告。

7 个恢复/配置路径必需，4 个已核验 H3 程序路径可显式纳入；其余路径全部拒绝。顶层分发工具和说明须由发布者另列完整文件清单及哈希，整包解压读回校验；不能仅用载荷 `verify` 代替 ZIP 交付验证。

本机隔离测试不等于另一台电脑或真实模型冷启动验收；具体正式包验证情况以包内版本说明为准。
