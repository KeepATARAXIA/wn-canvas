# MiniMax H3 / 安装与连接

适用于 WN Canvas Windows 无模型运行版。资料核对日期：2026-10-13。

**已有兼容的 H3 后端，可以按第一部分连接。全新安装者请先阅读第三部分的兼容缺口，再决定是否下载模型。** 画布不会代为安装 Python、ComfyUI、模型或节点，也不会自动启动 H3 服务。

## Connect / 连接已有 H3 后端

1. 先打开自己的 ComfyUI，确认它能独立运行 H3。默认地址为 `http://127.0.0.1:8188`；能够打开页面只代表服务在线，还需检查节点、模型与实际生成。
2. 允许实际画布地址跨域访问。画布默认来源为 `http://localhost:3000`；若用 `--port 13117` 启动画布，来源就是 `http://localhost:13117`。`localhost` 和 `127.0.0.1` 不能混用。
3. 在 ComfyUI 原有启动参数后添加以下参数，保留其他必要参数。修改前保存原启动文件，并先正常结束这个 ComfyUI 实例再重启：

```text
--listen 127.0.0.1 --port 8188 --enable-cors-header http://localhost:3000
```

官方 Windows Portable 的目录结构为 `python_embeded/` 和 `ComfyUI/`。在该 Portable 根目录打开 PowerShell，可使用下面的启动形式；其他整合包应使用其原有 Python 和启动入口：

```powershell
.\python_embeded\python.exe -s ComfyUI\main.py --windows-standalone-build --listen 127.0.0.1 --port 8188 --enable-cors-header http://localhost:3000
```

4. 返回 WN 的“配置 → 模型与服务 → 连接已有服务”，选择“H3 · 视频”并打开连接配置。接口地址填 **`http://127.0.0.1:8188`**，保留内置 H3 调用脚本。无鉴权的本机 ComfyUI 不需要 API Key。
5. 点击“测试连接”并保存。无模型运行版没有旧整合包的 `/api/comfyui` 代理；请把旧 `http://localhost:3000/api/comfyui` 地址改为上面的后端直连地址。实时进度还会连接同一后端的 `/ws`。
6. 初次验证使用一个新画布、5 秒、480P、小量参考素材。在 H3 视频节点的模式菜单选择 **“原生质量”**，并保持 **“SageAttention 注意力加速”** 关闭。根据下表选择后端已有的功能；不要同时运行其他占用显存的生成任务。成功返回视频后，再检查停止、刷新恢复和所需参考模式。

| 模式或功能 | 后端必须具备 | 缺失时怎么处理 |
|---|---|---|
| 基础 H3 | 对应模型、编码器、音视频 VAE，以及 `MiniMaxH3ReferenceToVideo` 等原生节点 | 先在 ComfyUI 中完成官方 H3 工作流 |
| TE 加速 | `TESpeedMiniMaxH3` 节点 | 选择“原生质量”，或在 TE-Speed 模式下关闭“TE-Speed 缓存加速”；不要从不明来源获取同名二进制 |
| Turbo | 对应 Turbo LoRA 和 `MiniMaxH3SigmaShift` 节点 | 安装匹配的权重后再选 Turbo，不用近似文件名代替 |
| Spectrum | `SpectrumApplyMiniMaxH3` 节点 | 未安装则不选择 Spectrum |
| SageAttention | WN 脚本要求的 `MiniMaxH3MemoryEfficientSageAttentionPatch` 及匹配运行依赖 | 初次连接保持关闭；其他 Sage 节点同样带有 Sage 名称，也不能直接替代 |
| 参考视频 | WN 的 `CanvasH3ReferenceVideo` 节点、配套预处理代码及可用 FFmpeg/ffprobe | 新装官方 ComfyUI 通常不具备这套 WN 扩展，先看第三部分 |

可以在浏览器打开 `http://127.0.0.1:8188/object_info/CanvasH3ReferenceVideo` 检查该节点。返回空对象表示未注册；节点存在也不能代替模型、FFmpeg 路径和真实生成验证。

## Install / 从零安装官方 H3

这部分用于准备可独立运行 H3 的 ComfyUI。完成官方工作流后，接入 WN 仍需第三部分的兼容检查。

### Environment / 准备后端

1. 阅读 [ComfyUI 官方 Windows Portable 安装说明](https://docs.comfy.org/installation/comfyui_portable_windows)，从官方入口获取符合显卡与驱动条件的运行包，解压到独立目录。不要覆盖正在使用的 WN 或其他 ComfyUI。
2. 按 [Comfy 官方 H3 教程](https://docs.comfy.org/tutorials/video/minimax/minimax-h3) 检查版本和所选权重的运行要求。官方基础 H3 工作流要求 ComfyUI 0.30.0 或更高；WN 既有环境记录为 **ComfyUI 0.35.0、PyTorch 2.13.0+cu130、RTX 5070 Ti 16GB**。这是历史运行记录，不是最低配置承诺，也不表示新的机器或新版本已经验收。
3. 可核验的 [ComfyUI v0.35.0 源码](https://github.com/Comfy-Org/ComfyUI/tree/40c4fcdf513a4523e39d54a9d391908af8df8171) 对应提交 `40c4fcdf513a4523e39d54a9d391908af8df8171`。源码标签不包含完整 Python/CUDA 环境，也不包含 WN 维护补丁；只固定这个标签仍不足以复现旧整合包。
4. 以下 INT8/NVFP4 文件是现有 WN 脚本使用的组合。先核对显卡、驱动、PyTorch 和 ComfyUI 对量化格式的支持；不要把“16GB 显存曾运行过”当作任意 16GB 显卡均可运行的保证。

## Compatibility / 新安装接入 WN 仍需完成的部分

**当前没有随本运行版公开交付一套已经完成干净安装验收的 WN H3 后端补丁包。** 官方 ComfyUI 能生成 H3 视频，不代表它已经具备 WN 的全部参考输入与加速能力。

- 既有 WN 后端改动了 `ComfyUI/comfy_extras/nodes_minimax_h3.py`，并配套 `canvas_h3_reference.py`。官方 v0.35.0 不含 `CanvasH3ReferenceVideo`。这些维护文件没有包含在本无模型运行版及当前公开源码中，本页不提供未经交付的补丁下载入口。
- 参考视频预处理还依赖 FFmpeg 和 ffprobe。旧实现按整合包的 `LosslessCut/resources` 布局寻找它们；只复制两个 Python 文件到新 ComfyUI 不能完成安装。需要先完成独立路径适配和验收，不能随意覆盖官方节点文件。
- TE-Speed 在既有环境中是额外的编译节点，未随公开源码分发。它不应成为新用户的必装依赖；Sage、Spectrum 也属于需要分别匹配的可选加速方案。
- WN 使用 `/prompt`、`/history`、`/queue`、`/ws`、`/api/jobs/{job_id}/cancel` 等后端接口。官方 v0.35.0 已包含定向取消与客户端任务 ID 支持；这些接口的存在仍不能替代端到端停止与恢复验证。

因此，没有旧兼容后端的用户，目前可以按官方指引先在 ComfyUI 中独立使用 H3；接入 WN 全功能前，需要取得适配后的维护文件、对应依赖清单并完成实际生成验证。若目标只是立即在画布里生成，可先配置自己已有的兼容云端服务，或使用已经验证过的 H3 后端。

## Troubleshooting / 常见问题

- **页面能打开，画布测试连接失败：** 检查接口是否为直连 `http://127.0.0.1:8188`；检查 CORS 是否与地址栏中的实际画布来源完全一致。修改来源后重启对应 ComfyUI。
- **提示没有模型或模型名不在列表：** 检查目录、原文件名及下载完整性，重启 ComfyUI 后再查看模型列表。不要通过改名掩盖不同权重版本。
- **提示缺 `CanvasH3ReferenceVideo`：** 服务缺少 WN 参考视频扩展；下载主模型不能解决此问题。
- **提示缺 TE/Sage/Spectrum：** 关闭对应加速选项，或切换为该后端确实支持的模式；不要安装来源和版本不明的二进制。
- **显存不足或速度慢：** 先减少时长、尺寸和参考素材，结束其他生成任务；权重大小、显存和运行速度不是同一回事。本页没有给出跨机器性能承诺。

本指南核验了公开来源和现有代码依赖，没有在本轮安装 ComfyUI、下载大权重或执行新的 GPU 生成。
