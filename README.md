# WN Canvas / WN 无限画布

把文字、参考素材、AI 生成和视频处理放在同一张画布里的本地创作工作台。

WN Canvas 基于 [basketikun/infinite-canvas](https://github.com/basketikun/infinite-canvas) 持续修改，保留原作者版权与 [MIT 许可证](LICENSE)。第三方资料、模型和可选工具各自适用其许可，见 [第三方说明](THIRD-PARTY-NOTICES.md)。

**当前为源码预览版。** 本目录提供画布源码和接入代码，不含模型、Python/Node 运行时或整合包内的第三方程序；尚未发布正式 Release 或免安装运行包。

基础画布已在 Windows 的全新独立目录完成安装和浏览器验收：使用 Node.js 24.15、npm 11.12，通过标准 `npm ci` 安装，并实际验证文字、图片、拖动、连线、编组复制和项目 ZIP 往返。此次验证在同一台电脑进行，不代表跨机器或全部可选能力已验收。根 `VERSION` 与 `CHANGELOG.md` 为沿用的构建输入，不代表本候选目录已正式发布。详细范围见 [验证记录](VALIDATION.md)。

## Features / 功能

- **多媒体画布**：组织文字、图片、视频、音频和生成配置，连接素材与结果，支持编组、复制、撤销与重做。
- **生成与编辑**：配置本地或云端模型，使用提示词和参考素材生成内容，在画布内继续修改和比较结果。
- **任务与资产**：查看生成队列、历史与耗时，整理、预览和复用素材，导出备份。
- **视频流程接入**：保留剪切、音轨、补帧、放大与超分的调用界面；实际执行需另备相应服务。
- **可选 Canvas Agent**：连接本机 Agent，通过 Codex 辅助组织提示词和操作画布。
- **节点扩展**：保留插件 SDK 和示例，可开发 Markdown、SVG、HTML、全景等自定义节点。

基础画布可单独启动。AI 生成、Agent 和视频工具需要各自的后端、账号、模型或依赖，不随启动器自动安装。

## Quick Start / 快速开始

### 1. 下载并解压源码

GitHub 仓库公开后，在仓库页面选择 **Code → Download ZIP**，解压到自己的项目目录。以下命令中的“项目根目录”，指同时包含 `web` 文件夹和 `一键启动.cjs` 的目录。请先解压，再运行启动入口。

### 2. 准备 Node.js

最低要求为 **Node.js 22.12+**，首发建议使用 [Node.js 24 LTS](https://nodejs.org/en/download) 和现代桌面浏览器。本次实测版本是 Node.js 24.15、npm 11.12；Node.js 22 尚未实际验收。Windows 提供批处理入口，其他系统尚未验收。

### 3. 安装前端依赖

在项目根目录打开终端，执行：

```powershell
cd web
npm ci
cd ..
```

此步骤会联网下载锁定依赖，首次安装需要可用的 npm 网络连接。

### 4. 启动画布

Windows 双击根目录的 `启动无限画布.bat`，或在项目根目录执行：

```powershell
node 一键启动.cjs
```

默认打开 `http://localhost:3000`。保持终端打开，按 `Ctrl+C` 结束本次启动的服务。若端口已占用，启动器会明确退出，不停止已有服务。

若 3000 端口已被占用，可指定另一个空闲端口：

```powershell
node 一键启动.cjs --port 13107
```

此时访问 `http://localhost:13107`；追加 `--no-open` 可只启动服务、不自动打开浏览器。尽量固定使用同一主机名和端口，以便继续访问原来的浏览器项目。可选后端的 Origin/CORS 可能默认只允许 `http://localhost:3000`，更换端口后需相应配置。

启动器不会下载依赖、启动 GPU/Python 服务或执行旧整合包更新器。缺少依赖时，按提示完成安装后再启动。

### 5. 完成第一次画布操作

1. 在“我的项目”中新建画布，点击左侧“文本”，双击节点正文输入文字，按 `Esc` 结束编辑。
2. 点击“上传素材”导入自己的图片，拖动节点排列位置，再从文本节点右侧连接点拖向图片节点。
3. 按住 `Shift` 依次点选两个节点，按 `Ctrl+G` 打组；右击组，选择“复制”，得到包含成员和内部连线的副本。
4. 左上角画布菜单选择“导出当前画布”，保存项目 ZIP。需要恢复时，回到“我的画布”，在“更多”中选择“导入画布”。导入会新增项目，原项目保留。

上述流程已用本地 PNG 实际走通，导入后刷新仍能显示素材、文字与连线；编辑导入的副本没有改变原项目。基础整理和备份不需要模型或 Agent。需要生成时，再到配置中添加自己的模型服务，并核对模型名称、接口地址和参数。

## Optional Services / 可选服务

| 能力 | 需要自行准备 | 当前交付边界 |
|---|---|---|
| 云端 AI 接口 | 账号、API Key、模型权限和额度 | 保留渠道与自定义调用能力；费用按服务商规则计算 |
| Ollama / LM Studio / OpenAI 兼容接口 | 已启动的本地服务及模型 | 保留配置入口；不附运行时和模型 |
| ComfyUI 图片与视频生成 | 兼容版本、模型、节点和可运行工作流 | 保留接入代码；Qwen、H3 的整套环境及维护补丁尚未形成独立安装交付 |
| 视频处理与 SeedVR2 超分 | Python、FFmpeg、Video2X、SeedVR2 等组件 | 保留桥接源码；仍有整合包路径约定，需完成适配后使用 |
| 本地提示词辅助 | 对应后端或本机 Agent | 保留四份带许可的离线资料包；未分发 MiniMax 官方提示指南正文 |
| 即梦网页桥接 | 自己的已登录网页、扩展和可用额度 | [扩展安装说明](browser-extension/jimeng-canvas-bridge/README.md)；受网页变化与服务规则影响 |
| 节点插件 | 插件代码或可信插件地址 | [SDK 与示例](plugins/canvas/README.md)；仅加载可信来源 |

Qwen-Image 2.1、MiniMax H3 等模型有独立使用和分发条款。画布代码开源不会改变模型许可，也不表示所有接入能力免费或可无限制商用。具体来源与待核事项见 [第三方说明](THIRD-PARTY-NOTICES.md)。

### Canvas Agent

在项目根目录执行一次安装与构建：

```powershell
cd canvas-agent
npm ci
npm run build
cd ..
```

然后启动画布与 Agent：

```powershell
node 一键启动.cjs --agent
```

Agent 默认地址为 `http://127.0.0.1:17371`。按终端输出，在画布 Agent 面板填写地址和连接 token；使用 Codex 前，先完成自己的 Codex 登录或配置。不要将 token、登录文件或账号配置上传到仓库。详见 [Canvas Agent](canvas-agent/README.md)。

### 本地 API 代理

浏览器跨域访问受限时，可在另一个终端从项目根目录运行：

```powershell
node canvas-proxy/index.js
```

默认地址为 `http://127.0.0.1:23210`，填入画布的本地代理配置。仅用于可信的本机使用，不要开放到公网。详见 [代理说明](canvas-proxy/README.md)。

## Updates / 升级

本源码预览版尚未启用在线更新，也没有正式 Release 更新通道。后续源码版本需手动下载、安装依赖并启动。升级前先导出画布 ZIP；如需备份渠道配置，请妥善保管含密钥的配置文件。建议将新版本解压到另一个目录，验证可用后再决定是否替换旧目录。

## Data and Access / 数据与访问

- 画布、素材和渠道配置主要保存在当前浏览器本地。更换浏览器、主机名或端口可能进入另一份存储；清理浏览器数据前先导出备份。
- 导入配置前会校验整个文件，错误文件保持现有设置。当前页面会话可撤销最后一次成功导入；撤销会回退之后的渠道和同步设置修改，刷新或关闭后不再保留这份撤销快照。
- 接入云端服务时，提示词和选中的素材会发送到该服务。Agent 请求也可能发送到所选模型服务。
- API Key、Agent token、工作文件和生成素材由使用者保管，不要放入 Issue、截图或公开压缩包。
- 本版本以本机使用为目标，未作为公网多用户服务验收。
