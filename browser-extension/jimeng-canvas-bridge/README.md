# 无限画布 · 即梦自动桥接

该 Chrome / Edge Manifest V3 扩展复用浏览器中已经登录的即梦网页，把无限画布的视频提示词、参数和参考素材提交到即梦，再把完成的视频导回画布。

## 安装

1. 在 Edge 打开 `edge://extensions/`，开启「开发人员模式」。
2. 点击「加载解压缩的扩展」，选择本目录 `browser-extension/jimeng-canvas-bridge`。
3. 打开并登录即梦官网，再刷新 `http://localhost:3000` 的无限画布。

扩展只声明无限画布本地地址和即梦官网权限，不读取或保存 Cookie。即梦网页结构变化时，可继续使用画布内的半自动打包、打开网页和手动导回功能。
